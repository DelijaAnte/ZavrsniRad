# GymBuddy

This is my **final thesis** project (FESB, University of Split — professional undergraduate Computer Science): a mobile app for workout logging and progress tracking in React Native.

Official thesis registration: [`docs/Obrazac-za-prijavu-zavrsnog-rada-Delija.pdf`](./docs/Obrazac-za-prijavu-zavrsnog-rada-Delija.pdf)

## Features

- Email sign-in / sign-up
- Weekly training plans (routines, days, exercises)
- Session logging (weight, reps, RPE) and saved history
- Progress views: tables, charts, consistency heatmap
- Profile: GitHub link, sign out, account deletion

## Tech

- Expo (SDK 54), Expo Router, React Native, TypeScript
- Supabase (Auth, PostgreSQL)
- react-native-chart-kit, react-native-svg
